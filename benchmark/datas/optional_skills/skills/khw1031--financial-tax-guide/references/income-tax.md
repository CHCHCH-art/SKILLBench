# 소득세 상세 가이드

> 가족 재무 상담 시 참고할 소득세, 연말정산, 금융소득세 상세 정보 (2024-2025 기준)

---

## 1. 종합소득세

### 소득 유형

| 소득 유형 | 내용 | 과세 방식 |
|----------|------|----------|
| 근로소득 | 급여, 상여, 인정상여 | 원천징수 + 연말정산 |
| 사업소득 | 자영업, 프리랜서 수입 | 종합소득세 신고 |
| 이자소득 | 예금/채권 이자 | 분리과세 또는 종합과세 |
| 배당소득 | 주식 배당금 | 분리과세 또는 종합과세 |
| 연금소득 | 공적/사적 연금 | 분리과세 또는 종합과세 |
| 기타소득 | 강연료, 인세, 복권당첨금 등 | 필요경비 차감 후 과세 |

### 종합소득세율 상세

| 과세표준 | 세율 | 누진공제 | 산출세액 계산 |
|---------|------|---------|-------------|
| 1,400만원 이하 | 6% | - | 과세표준 x 6% |
| 1,400만~5,000만원 | 15% | 126만원 | 과세표준 x 15% - 126만원 |
| 5,000만~8,800만원 | 24% | 576만원 | 과세표준 x 24% - 576만원 |
| 8,800만~1.5억원 | 35% | 1,544만원 | 과세표준 x 35% - 1,544만원 |
| 1.5억~3억원 | 38% | 1,994만원 | 과세표준 x 38% - 1,994만원 |
| 3억~5억원 | 40% | 2,594만원 | 과세표준 x 40% - 2,594만원 |
| 5억~10억원 | 42% | 3,594만원 | 과세표준 x 42% - 3,594만원 |
| 10억원 초과 | 45% | 6,594만원 | 과세표준 x 45% - 6,594만원 |

*지방소득세 10% 추가 → 최고 세율 실효 49.5%*

**과세표준 산출 흐름**:

```
총급여
 - 근로소득공제 (급여 구간별 자동 계산)
 = 근로소득금액
 - 인적공제, 특별소득공제, 기타소득공제
 = 과세표준
 x 세율 - 누진공제
 = 산출세액
 - 세액공제 (근로소득, 자녀, 연금저축, 의료비, 교육비 등)
 = 결정세액
 - 기납부세액 (원천징수)
 = 추가납부 또는 환급
```

## 2. 연말정산 소득공제

### 인적공제

| 공제 유형 | 대상 | 공제 금액 |
|----------|------|----------|
| 기본공제 | 본인, 배우자, 부양가족 | 1인당 150만원 |
| 경로우대 | 만 70세 이상 | 1인당 100만원 추가 |
| 장애인 | 장애인 | 1인당 200만원 추가 |
| 부녀자 | 해당 여성 근로자 | 50만원 추가 |
| 한부모 | 배우자 없이 자녀 부양 | 100만원 추가 |

**부양가족 요건**:
- 배우자: 연 소득 100만원 이하 (근로소득만 있으면 총급여 500만원 이하)
- 직계존속: 만 60세 이상, 연 소득 100만원 이하
- 직계비속: 만 20세 이하, 연 소득 100만원 이하
- 형제자매: 만 20세 이하 또는 60세 이상, 소득 요건 충족

### 신용카드 등 소득공제

| 구분 | 공제율 | 비고 |
|------|-------|------|
| 신용카드 | 15% | 기본 |
| 체크카드/현금영수증 | 30% | 신용카드 대비 2배 |
| 전통시장 | 40% | 추가 한도 100만원 |
| 대중교통 | 80% | 추가 한도 100만원 |
| 도서/공연/영화 | 30% | 총급여 7,000만원 이하만 |

**공제 적용 순서**: 총급여의 25% 초과 사용분부터 공제 (신용카드 → 체크카드/현금영수증 순)

**소득공제 한도**:

| 총급여 | 기본 한도 |
|--------|----------|
| 7,000만원 이하 | 300만원 |
| 7,000만~1.2억원 | 250만원 |
| 1.2억원 초과 | 200만원 |

**절세 팁**:
- 총급여 25%까지는 신용카드로 혜택 극대화 (카드 포인트, 할인 등)
- 25% 초과분은 체크카드/현금영수증으로 전환하여 공제율 2배
- 전통시장, 대중교통은 별도 추가 한도 활용

### 기타 소득공제

| 항목 | 내용 | 한도 |
|------|------|------|
| 국민연금 | 근로자 부담분 | 전액 공제 |
| 건강보험료 | 근로자 부담분 | 전액 공제 |
| 고용보험료 | 근로자 부담분 | 전액 공제 |
| 주택임차차입금 원리금상환 | 무주택 세대주 | 연 400만원 |
| 장기주택저당차입금 이자상환 | 취득 당시 기준시가 5억 이하 | 연 300~1,800만원 |
| 개인연금저축 | 2000.12.31 이전 가입분 | 연 72만원 |
| 소기업/소상공인 공제 (노란우산) | 사업자 | 연 200~500만원 |

## 4. 금융소득세

### 이자/배당소득 과세

| 구분 | 과세 방식 | 세율 | 비고 |
|------|----------|------|------|
| 연간 2,000만원 이하 | 원천징수 분리과세 | 15.4% | 별도 신고 불필요 |
| 연간 2,000만원 초과 | 금융소득종합과세 | 기본세율 (6~45%) + 지방세 | 다른 소득과 합산 |

**금융소득종합과세 계산**:

```
금융소득 3,000만원인 경우:
- 2,000만원: 원천징수세율 14% 적용 = 280만원
- 초과 1,000만원: 다른 소득과 합산하여 기본세율 적용
- 단, 종합과세 산출세액이 분리과세 산출세액보다 적으면 분리과세 적용 (유리 선택)
```

**금융소득종합과세 회피 전략**:
- 가족 간 명의 분산 (증여세 면제한도 내)
- ISA 활용 (비과세 + 분리과세)
- 비과세 금융상품 활용 (장기저축성보험 등)
- 채권 매매차익 활용 (비과세 대상)
- 해외주식 양도차익은 금융소득에 미포함 (별도 양도소득)

### 금융투자소득세 (금투세) 관련

| 항목 | 내용 |
|------|------|
| 도입 경과 | 당초 2023년 시행 예정이었으나 유예/폐지 논의 중 |
| 현재 상태 | 2025년 기준 시행 여부 정치적 논의 진행 중 |
| 예정 내용 | 국내주식 매매차익 5,000만원 초과분 22% 과세 |
| 해외주식 | 현행: 250만원 공제 후 22% 양도소득세 (금투세와 별개) |

**상담 포인트**:
- 금투세 시행 여부에 따라 투자 전략이 달라질 수 있음
- 현행 기준: 국내주식 매매차익은 일반투자자 비과세
- 대주주 요건 (종목당 10억원 이상 또는 지분율 1~4%) 해당 시 양도세 과세
- 해외주식은 금투세와 무관하게 현행 양도소득세 적용

### 주요 비과세/분리과세 금융상품

| 상품 | 비과세/감면 내용 | 조건 |
|------|----------------|------|
| 장기저축성보험 | 보험차익 비과세 | 10년 이상 유지, 납입한도 충족 |
| 조합 출자금/예탁금 | 비과세 | 농협/수협/신협 등, 3,000만원 한도 |
| 개인투자용 국채 | 분리과세 14% | 만기보유 시 |
| ISA | 비과세 200~400만원 + 9.9% 분리과세 | 3년 의무가입 |
| 연금저축/IRP | 납입 시 세액공제, 수령 시 저율과세 | 55세 이후 연금 수령 |

### 맞벌이 부부 절세 전략

| 전략 | 내용 |
|------|------|
| 부양가족 배분 | 세율 높은 쪽에 인적공제 배분 |
| 의료비 | 총급여 낮은 쪽에 집중 (3% 문턱 낮춤) |
| 카드 사용 | 각자 총급여 25% 초과하도록 배분 |
| 교육비 | 자녀 기본공제 받는 쪽에서 공제 |
| 기부금 | 세율 높은 쪽에서 공제 |

**상담 포인트**:
- 부부 중 세율이 높은 사람에게 공제 항목 집중이 일반적으로 유리
- 의료비는 예외: 총급여 낮은 쪽이 3% 문턱을 넘기 쉬움
- 매년 소득 변동에 따라 최적 배분이 달라질 수 있으므로 매년 점검
