# 증여세/상속세 상세 가이드

> 가족 재무 상담 시 참고할 증여세, 상속세, 자산이전 절세 전략 (2024-2025 기준)

---

## 1. 증여세

### 증여세 면제한도 (10년 합산)

| 증여자 → 수증자 | 면제한도 | 비고 |
|----------------|---------|------|
| 배우자 → 배우자 | 6억원 | 혼인 기간 무관 |
| 직계존속 → 성인 자녀 | 5,000만원 | 만 19세 이상 |
| 직계존속 → 미성년 자녀 | 2,000만원 | 만 19세 미만 |
| 직계비속 → 직계존속 | 5,000만원 | 자녀가 부모에게 |
| 기타 친족 (6촌 이내 혈족, 4촌 이내 인척) | 1,000만원 | |

*10년 단위로 면제한도 갱신 (동일인으로부터 증여 합산)*

### 증여세/상속세 세율 (동일 세율 적용)

| 과세표준 | 세율 | 누진공제 |
|---------|------|---------|
| 1억원 이하 | 10% | - |
| 1억~5억원 | 20% | 1,000만원 |
| 5억~10억원 | 30% | 6,000만원 |
| 10억~30억원 | 40% | 1.6억원 |
| 30억원 초과 | 50% | 4.6억원 |

### 증여세 계산

```
증여재산가액
 - 비과세 재산 (사회통념상 인정되는 피부양자 생활비, 교육비 등)
 - 증여재산공제 (면제한도)
 = 과세표준
 x 세율 - 누진공제
 = 산출세액
 - 세대생략 할증 (손자녀 등에게 증여 시 30% 할증, 미성년 40%)
 + 신고세액공제 (자진신고 시 3%)
 = 납부세액
```

### 증여 재산 평가

| 재산 유형 | 평가 방법 |
|----------|----------|
| 부동산 | 시가 (매매사례가, 감정가), 없으면 기준시가 |
| 상장주식 | 평가기준일 전후 2개월 종가 평균 |
| 비상장주식 | 순자산가치와 순손익가치 가중평균 |
| 현금/예금 | 증여일 잔액 |
| 보험금 | 해약환급금 또는 보험금 |

**증여 추정/의제 주의사항**:

| 유형 | 내용 |
|------|------|
| 저가 양수 | 시가와 대가의 차이가 3억원 이상 또는 시가의 30% 이상이면 증여 추정 |
| 부담부 증여 | 채무 인수분은 양도소득세 과세, 나머지 증여세 |
| 명의신탁 | 타인 명의 등기/등록 시 증여세 과세 |
| 금전 무상대출 | 1억원 이상 무상대출 시 이자상당액(4.6%) 증여 |
| 부동산 무상사용 | 5억원 이상 부동산 무상사용 시 증여세 과세 |

**상담 포인트**:
- 증여세 신고기한: 증여일이 속하는 달의 말일부터 3개월 이내
- 자진신고 시 3% 세액공제 혜택 (기한 내 신고 필수)
- 증여 후 10년 이내 증여자 사망 시 상속재산에 합산 과세
- 부담부 증여 활용 시 채무 인수 입증 철저히 (차용증, 이자 지급 내역)

## 2. 상속세

### 상속공제 체계

| 공제 유형 | 내용 | 한도 |
|----------|------|------|
| 기초공제 | 모든 상속 | 2억원 |
| 인적공제 | 자녀 1인당 5,000만원, 미성년 1,000만원x잔여연수, 65세 이상 5,000만원, 장애인 1,000만원x잔여연수 | |
| **일괄공제** | 기초+인적 대신 선택 가능 | **5억원** |
| 배우자상속공제 | 법정상속분 한도 내 실제 상속액 | 최소 5억~최대 30억원 |
| 금융재산공제 | 순금융재산의 20% | 최대 2억원 |
| 동거주택 상속공제 | 피상속인과 10년 이상 동거 | 최대 6억원 |
| 가업상속공제 | 중소/중견기업 | 최대 600억원 |
| 영농상속공제 | 영농 승계 | 최대 30억원 |

**일괄공제 vs 기초+인적공제**:
- 대부분의 경우 일괄공제(5억원)가 유리
- 부양가족이 많고 미성년/장애인이 있으면 인적공제 합산이 유리할 수 있음
- 배우자상속공제는 일괄공제와 별도 적용

### 상속세 계산 흐름

```
총상속재산가액
 + 추정상속재산 (사전 처분 재산 등)
 + 사전증여재산 (10년 이내)
 - 비과세 재산
 - 공과금/장례비/채무
 = 상속세 과세가액
 - 상속공제 (일괄공제 5억 + 배우자상속공제 등)
 = 과세표준
 x 세율 - 누진공제
 = 산출세액
 + 세대생략 할증 (30~40%)
 - 세액공제 (신고공제 3%, 기납부세액 공제 등)
 = 납부세액
```

### 상속세 실효세율 예시

| 상속재산 | 배우자 有 (배우자공제 5억 + 일괄 5억) | 배우자 無 (일괄 5억) |
|---------|-----------------------------------|-------------------|
| 10억원 | 0원 (공제 내) | 약 0.9억원 |
| 20억원 | 약 1.5억원 | 약 3.0억원 |
| 30억원 | 약 3.5억원 | 약 5.8억원 |
| 50억원 | 약 8.5억원 | 약 13.5억원 |

*배우자상속공제 금액에 따라 크게 변동, 대략적 참고치*

**상담 포인트**:
- 상속세 신고기한: 사망일이 속하는 달의 말일부터 6개월 이내
- 배우자상속공제를 최대한 활용하려면 배우자가 실제 상속받아야 함
- 동거주택 상속공제(최대 6억)는 동거 기간 10년, 무주택 등 요건 엄격
- 상속재산 평가 시 시가 우선 (감정평가 활용으로 절세 가능성)
- 사전증여재산 합산 (10년) 유의: 상속 직전 급하게 증여해도 합산됨

## 3. 자산이전 절세 전략

### 사전증여 전략

#### 10년 주기 증여 활용

| 전략 | 실행 방법 | 절세 효과 |
|------|----------|----------|
| 배우자 증여 | 10년마다 6억원씩 | 상속재산 축소 |
| 성인 자녀 증여 | 10년마다 5,000만원씩 | 장기적 면제한도 극대화 |
| 미성년 자녀 증여 | 10년마다 2,000만원씩 | 출생 시부터 시작하면 효과 큼 |
| 며느리/사위 증여 | 10년마다 1,000만원씩 | 세대 분산 효과 |

**장기 사전증여 시뮬레이션 (자녀 1인 기준)**:

```
출생 시: 2,000만원 증여 (면제한도 내, 세금 0)
10세: 2,000만원 추가 증여 (면제한도 내, 세금 0)
20세 (성인): 5,000만원 증여 (면제한도 내, 세금 0)
30세: 5,000만원 증여 (면제한도 내, 세금 0)
→ 30세까지 총 1.4억원 무세금 이전 (투자수익 별도)
```

#### 증여 시 유리한 자산

| 자산 유형 | 이유 |
|----------|------|
| 미래 가치 상승 자산 | 증여 시점 저평가 → 향후 상승분 비과세 |
| 수익 발생 자산 | 증여 후 수익은 수증자 소득 → 소득 분산 |
| 일시적 저평가 자산 | 시가 하락 시점 활용 |
| 비상장주식 (저평가) | 평가 방법 차이 활용 |

#### 증여 시 불리한 자산

| 자산 유형 | 이유 |
|----------|------|
| 양도차익 큰 부동산 | 부담부 증여 시 양도세 발생 |
| 매도 예정 자산 | 증여 후 즉시 매도 시 과세 이슈 |
| 가치 하락 예상 자산 | 증여 후 가치 하락 시 손해 |

### 부담부 증여 전략

| 항목 | 내용 |
|------|------|
| 개념 | 채무(대출)를 함께 이전하는 증여 |
| 증여세 과세 | 재산가액 - 채무액 = 증여세 과세대상 |
| 양도세 과세 | 채무 인수분은 증여자에게 양도소득세 |
| 활용 시점 | 취득가액이 높은 자산, 양도세 부담 낮을 때 |

**예시**:

```
부동산 시가 10억원 (취득가 8억원), 담보대출 4억원

일반 증여:
- 증여세 과세가액: 10억 - 5,000만원(공제) = 9.5억
- 증여세: 약 2.3억원

부담부 증여 (대출 4억 이전):
- 증여세 과세가액: (10억-4억) - 5,000만원 = 5.5억
- 증여세: 약 1.1억원
- 양도세: (8억취득→4억양도) → 양도차익 작아 양도세 소액
- 총 세금: 약 1.2억원 → 약 1.1억 절세
```

### 배우자 간 자산이전

| 전략 | 내용 | 효과 |
|------|------|------|
| 배우자 증여 후 양도 | 배우자에게 증여(6억 공제) 후 배우자가 양도 | 취득가액 증가로 양도세 감소 |
| 소득 분산 | 수익형 자산 배우자 증여 | 소득세 분산 효과 |
| 상속세 대비 | 배우자에게 사전 증여 | 상속재산 축소 |

**주의사항**:
- 배우자 증여 후 양도 시, 증여받은 날부터 5년 이내 양도하면 당초 취득가액 적용 (이월과세)
- 증여세 면제한도 활용해도 반드시 증여세 신고 권장 (향후 입증)

### 상속 대비 종합 전략

| 시기 | 전략 | 핵심 |
|------|------|------|
| 조기 (50대~) | 사전증여 시작 | 10년 주기 면제한도 활용 |
| 중기 (60대) | 자산 구조 정리 | 부동산→금융자산 전환, 채무 정리 |
| 후기 (70대~) | 상속 설계 | 유언장, 배우자공제 극대화, 동거주택 요건 |
| 사후 | 신고 최적화 | 공제 극대화, 재산평가 최적화 |

### 세대 생략 증여/상속 (손자녀)

| 항목 | 내용 |
|------|------|
| 개념 | 부모 세대 건너뛰고 손자녀에게 직접 이전 |
| 할증 | 30% 할증 (미성년 수증자는 40%) |
| 장점 | 1회 이전으로 2회 과세 회피 (부모→자녀→손자녀) |
| 손익분기 | 이전 재산이 클수록, 세율이 높을수록 유리 |

## 4. 절세 전략 종합 요약

### 연말정산 절세 체크리스트

```
[ ] 연금저축 + IRP 합산 700만원 납입했는가?
[ ] 신용카드 사용액이 총급여 25% 넘은 후 체크카드로 전환했는가?
[ ] 부양가족 공제를 세율 높은 배우자에게 배분했는가?
[ ] 의료비 공제를 총급여 낮은 배우자에게 집중했는가?
[ ] 월세 세액공제 대상이면 증빙을 준비했는가?
[ ] 기부금 영수증을 확보했는가?
```

### 금융소득 절세 체크리스트

```
[ ] 연간 금융소득이 2,000만원 초과 예상인가? → 분산 검토
[ ] ISA 한도를 활용하고 있는가?
[ ] 비과세 금융상품(저축성보험, 조합예금)을 활용하고 있는가?
[ ] 해외주식 양도차익 250만원 공제를 활용하고 있는가?
[ ] 배우자/가족 명의 분산이 가능한가? (증여 면제한도 내)
```

### 부동산 절세 체크리스트

```
[ ] 1세대 1주택 비과세 요건(보유/거주 기간)을 충족하는가?
[ ] 장기보유특별공제 요건을 확인했는가?
[ ] 다주택자 중과 한시 배제 기간을 확인했는가?
[ ] 취득 시 생애최초/신혼부부 감면을 적용할 수 있는가?
[ ] 종부세 1세대 1주택 고령/장기보유 공제를 받고 있는가?
[ ] 필요경비 증빙(인테리어, 중개비)을 보관하고 있는가?
```

### 증여/상속 절세 체크리스트

```
[ ] 10년 주기 면제한도를 활용한 사전증여를 하고 있는가?
[ ] 증여세 신고를 기한 내 자진신고했는가? (3% 공제)
[ ] 미래 가치 상승 자산을 우선 증여하고 있는가?
[ ] 배우자상속공제를 최대한 활용할 수 있는 구조인가?
[ ] 유언장/유언대용신탁 등을 준비했는가?
[ ] 세대 생략 증여의 할증 대비 이점을 분석했는가?
```

### 절세 시 주의사항

| 주의 항목 | 내용 |
|----------|------|
| 세무 리스크 | 과도한 절세는 탈세로 간주될 수 있음 |
| 입증 책임 | 자금출처, 차용 관계 등 입증 준비 필수 |
| 법령 변경 | 세법은 매년 개정, 최신 기준 확인 필수 |
| 전문가 상담 | 고액 자산이전, 복잡한 사안은 세무사/변호사 상담 권장 |
| 종합 설계 | 절세와 자산 운용을 종합적으로 고려 (세금만 보면 안 됨) |
