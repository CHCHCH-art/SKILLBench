# 부동산 세금 상세 가이드

> 가족 재무 상담 시 참고할 부동산 관련 세금 정보 (2024-2025 기준)

---

## 1. 취득세

### 주택 취득세율

| 주택 가액 / 보유 수 | 1주택 | 2주택 (조정지역) | 2주택 (비조정) | 3주택 이상 |
|---------------------|-------|----------------|---------------|-----------|
| 6억원 이하 | 1% | 8% | 1~3% | 12% |
| 6억~9억원 | 1~3% (비례) | 8% | 1~3% | 12% |
| 9억원 초과 | 3% | 8% | 3% | 12% |

*농어촌특별세, 지방교육세 추가 (약 0.2~0.6%p)*

**취득세 주요 특례**:

| 특례 | 내용 | 조건 |
|------|------|------|
| 생애최초 주택 | 200만원 감면 | 본인/배우자 무주택, 수도권 4억/비수도권 3억 이하 |
| 신혼부부 | 50% 감면 | 혼인신고 5년 이내, 3억 이하 |
| 다자녀 | 50% 감면 | 미성년 자녀 3명 이상 |
| 일시적 2주택 | 1주택 세율 적용 | 신규 취득 후 3년 내 기존 주택 처분 |

**상담 포인트**:
- 취득세는 잔금일 또는 등기일 중 빠른 날로부터 60일 이내 신고/납부
- 조정대상지역 여부에 따라 다주택 세율이 크게 달라짐
- 법인 취득 시 12% 중과 (주택)
- 분양권, 입주권도 주택 수 포함 여부 확인 필요

## 2. 재산세

### 재산세율 (주택)

| 과세표준 (공시가격 x 60%) | 세율 |
|--------------------------|------|
| 6,000만원 이하 | 0.1% |
| 6,000만~1.5억원 | 0.15% (누진) |
| 1.5억~3억원 | 0.25% (누진) |
| 3억원 초과 | 0.4% (누진) |

**재산세 특례**:

| 특례 | 내용 |
|------|------|
| 1세대 1주택 | 공시가격 9억 이하 시 세율 특례 (0.05~0.35%) |
| 재산세 도시지역분 | 0.14% 추가 (도시계획세 통합) |
| 지방교육세 | 재산세의 20% 추가 |

**납부 시기**:
- 7월: 주택분 1/2 + 건물분
- 9월: 주택분 1/2 + 토지분

**상담 포인트**:
- 재산세는 매년 6월 1일 기준 소유자에게 부과 (매매 시 기준일 유의)
- 공시가격 변동에 따라 세부담 상한제 적용 (전년 대비 105~130% 상한)
- 종부세와 재산세는 이중과세 조정 (종부세에서 재산세 공제)

- 공시가격 현실화 계획에 따른 중장기 부담 변화 유의

## 4. 양도소득세

### 기본 세율 (주택 외 일반자산 포함)

| 과세표준 | 세율 | 누진공제 |
|---------|------|---------|
| 1,400만원 이하 | 6% | - |
| 1,400만~5,000만원 | 15% | 126만원 |
| 5,000만~8,800만원 | 24% | 576만원 |
| 8,800만~1.5억원 | 35% | 1,544만원 |
| 1.5억~3억원 | 38% | 1,994만원 |
| 3억~5억원 | 40% | 2,594만원 |
| 5억~10억원 | 42% | 3,594만원 |
| 10억원 초과 | 45% | 6,594만원 |

### 주택 양도소득세 주요 규정

#### 1세대 1주택 비과세

| 요건 | 내용 |
|------|------|
| 보유 기간 | 2년 이상 (조정지역 취득: 2년 거주 추가) |
| 양도가액 | 12억원 이하: 전액 비과세 |
| 양도가액 12억 초과 | 12억 초과분만 과세 |
| 일시적 2주택 | 신규 취득 후 3년 내 기존 주택 양도 시 비과세 |

**12억원 초과 시 계산**:

```
양도차익 x (양도가액 - 12억원) / 양도가액 = 과세 대상 양도차익
```

#### 다주택자 양도세 중과

| 주택 수 | 기본세율 + 중과 | 비고 |
|---------|---------------|------|
| 조정지역 2주택 | 기본세율 + 20%p | 한시 배제 여부 확인 필요 |
| 조정지역 3주택 이상 | 기본세율 + 30%p | 한시 배제 여부 확인 필요 |
| 비조정지역 | 기본세율 적용 | 중과 없음 |

*중과 한시 배제 기간 확인 필수 (정부 정책에 따라 변동)*

### 장기보유특별공제

#### 일반자산 (주택 외)

| 보유 기간 | 공제율 |
|----------|--------|
| 3년 이상 | 연 2% (최대 30%) |

#### 1세대 1주택 (거주기간 요건 충족 시)

| 보유/거주 기간 | 보유 공제 | 거주 공제 | 합산 |
|--------------|----------|----------|------|
| 3년 | 12% | 12% | 24% |
| 4년 | 16% | 16% | 32% |
| 5년 | 20% | 20% | 40% |
| 6년 | 24% | 24% | 48% |
| 7년 | 28% | 28% | 56% |
| 8년 | 32% | 32% | 64% |
| 9년 | 36% | 36% | 72% |
| 10년 이상 | 40% | 40% | 80% |

*보유 공제: 연 4% (최대 40%), 거주 공제: 연 4% (최대 40%)*

### 양도소득세 계산 흐름

```
양도가액
 - 취득가액 (실거래가)
 - 필요경비 (취득세, 중개보수, 인테리어 등)
 = 양도차익
 - 장기보유특별공제
 = 양도소득금액
 - 기본공제 (250만원)
 = 과세표준
 x 세율
 = 산출세액
```

### 비과세/감면 특례

| 특례 | 내용 | 조건 |
|------|------|------|
| 1세대 1주택 | 비과세 | 2년 보유(+거주), 12억 이하 |
| 일시적 2주택 | 비과세 | 3년 내 기존 주택 양도 |
| 상속주택 | 비과세 특례 | 상속받은 주택+기존 1주택 |
| 혼인 합가 | 비과세 특례 | 혼인으로 2주택, 5년 내 양도 |
| 장기임대주택 | 감면 | 등록 임대, 8년/10년 |
| 농지 | 감면 | 8년 이상 자경, 1억원 한도 |

**상담 포인트**:
- 양도세는 양도일이 속하는 달의 말일부터 2개월 이내 예정신고
- 1세대 1주택 비과세 판단 시 부수토지 포함 여부, 고가주택 판단 유의
- 분양권/입주권 양도 시 주택 수 포함 여부 확인
- 다주택자 중과 한시 배제 기간은 정부 정책에 따라 수시 변동
- 필요경비(인테리어, 중개비 등) 증빙 보관 필수 (양도차익 감소 효과)
- 양도 전 세무사 상담 권장 (특히 다주택, 고가주택, 비거주자)
