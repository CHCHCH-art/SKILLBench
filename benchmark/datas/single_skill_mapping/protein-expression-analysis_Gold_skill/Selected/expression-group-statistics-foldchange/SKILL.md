---

## Dependency precheck

Run `scripts/ensure_dependencies.sh --check` before the procedure. If it reports missing dependencies, run `scripts/ensure_dependencies.sh --install`, then rerun `--check`.

## Parameter binding rule

Bind values, paths, labels, schema names, limits, thresholds, ranges, and output conventions explicitly supplied by the current task specification at execution time. Do not promote task-provided values to SKILL constants. Constants labeled **reference defaults** below apply only when the current task specification does not provide that parameter.

## Procedure
1. Bind control/treated group labels, sample-group row, protein matrix, statistics destinations, fold-change destinations, and workbook formatting constraints from the current task specification.
2. Determine which matrix columns belong to each group by the task-provided group label cells. For each target protein write formulas for group `AVERAGE` and sample standard deviation `STDEV.S` over the corresponding expression cells; preserve the layout/order specified by the current workbook.
3. For each protein write `log2_fold_change = treated_mean - control_mean` and ordinary fold change with Calc `POWER(2; log2_fold_change)` (or the equivalent exact formula syntax generated by this procedure).
4. Recalculate all formulas through LibreOffice and save the workbook without changing unrelated styles, colors, fonts, sheets, or adding macros.

## Checks
Verify formulas, not constants, occupy every requested yellow/output cell and calculated fold change is consistent with its displayed log2 difference.

If any required check fails and no reference retry/fallback is explicitly stated above, abort this step and do not emit downstream output.
