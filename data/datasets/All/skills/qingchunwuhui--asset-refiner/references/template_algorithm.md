## 填写指南

1. **核心思想**：一句话抓住本质，不要复制教科书定义
2. **伪代码**：必须清晰易懂，不要写成真实代码
3. **复杂度分析**：必须有推导过程，不要只给结论
4. **适用场景**：必须具体，给出数据特征和规模
5. **对比分析**：必须有同类算法对比，帮助选择决策
6. **代码实现**：必须可运行，有注释，有示例

## 与五层结构模板的区别

| 维度     | 算法模板             | 五层结构模板       |
| -------- | -------------------- | ------------------ |
| 核心目标 | 理解原理、掌握实现   | 改变认知、指导行为 |
| 重点章节 | 复杂度分析、伪代码   | 归因分析、底层逻辑 |
| 证明方式 | 数学推导、性能测试   | 案例验证、实战反馈 |
| 典型内容 | 排序、搜索、动态规划 | 思维模型、工作方法 |
