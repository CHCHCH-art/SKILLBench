## 填写指南

1. **概述**：一句话说清楚，不要假设读者知道背景
2. **适用场景**：必须具体，避免"各种场景都能用"这种空话
3. **参数说明**：必须完整，包括类型、必填性、默认值
4. **代码示例**：必须可运行，不要伪代码
5. **注意事项**：重点写"你当时踩过的坑"，不要写显而易见的东西
6. **参考资料**：如果是从官方文档提炼的，必须注明出处

## 与五层结构模板的区别

| 维度     | 技术文档模板       | 五层结构模板       |
| -------- | ------------------ | ------------------ |
| 核心目标 | 掌握用法           | 改变认知           |
| 重点章节 | 参数说明、代码示例 | 归因分析、底层逻辑 |
| 适用对象 | 程序员、工程师     | 泛用人群           |
| 典型内容 | API、脚本、配置    | 方法论、心智模型   |
